# StudyBuild Challenge — Data Cleaning

This project was completed as part of the **StudyBuild Challenge**. This notebook focuses on identifying and handling data-quality issues. Each issue was handled separately.

### Issues Identified

1. **Null values**
2. **Age:** Invalid values (`0` and `999`)
3. **Purchase Amount:** One negative value and two potential outliers
4. **Discount:** One negative value
5. **Returned:** One ambiguous `"Maybe"` value
6. **City:** Inconsistent capitalization and typos (`Ahwaz`, `Mashad`)
7. **Order Date:** One inverted date format and one invalid month (`13`)
8. **Duplicate:** One duplicated user record
9. **Email:** One malformed email address
